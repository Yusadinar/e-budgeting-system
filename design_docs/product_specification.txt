PRODUCT SPECIFICATION DOCUMENT: E-BUDGETING SYSTEM

1. PROJECT OVERVIEW
-------------------
The E-Budgeting System is a web-based application designed to streamline the corporate budgeting process. It manages the entire lifecycle of budget management, from annual allocation and department-level uploads to the submission and multi-level approval of purchase requests.

2. TARGET AUDIENCE & ROLES
--------------------------
- Staff/User: Submit budget requests (PPBJ, Proposal Harga, Internal Agreement).
- Kepala Departemen (Ka. Dept): Upload budgets via Excel, approve departmental requests.
- Kepala Divisi (Ka. Div): Intermediate approval level.
- Directors (Finance, Management, President): High-level monitoring and final approvals.
- Superadmin: System administration, user management, department configuration, and audit logs.

3. CORE FUNCTIONALITIES
-----------------------

3.1. Authentication & Authorization
- Secure login and registration using Laravel Breeze.
- Role-Based Access Control (RBAC) ensuring users only access features relevant to their position.
- Profile management for individual users.

3.2. Budget Management
- Annual Budget Allocation: Define budget limits for each department.
- Excel Bulk Upload: Specialized tool for Ka. Dept to upload large budget datasets using standardized templates.
- Budget Tracking: Real-time calculation of 'Allocated', 'Reserved' (pending approval), and 'Used' budgets.

3.3. Procurement Workflow (Pengajuan)
A three-step submission process:
1. PPBJ (Permintaan Pembelian Barang dan Jasa): Initial request for goods/services.
2. Proposal Harga (PH): Submission of price quotes and vendor comparisons.
3. Internal Agreement (IA): Finalization of terms for internal record and final approval.

3.4. Multi-Level Approval System
- Sequential approval workflow tailored to company hierarchy.
- QR Code Approval: Unique signed URLs generated for one-click approval via email or physical printouts.
- Reject/Revision handling with comments.

3.5. Tracking & Monitoring
- Tracking Dashboard: Status overview of all active submissions.
- Timeline View: Detailed history of who approved what and when for every request.
- Director Dashboard: High-level financial overview and utilization charts.

3.6. Administration
- User Management: Create, edit, and assign roles to employees.
- Department Management: Configure organizational units.
- Audit Logs: Track system activities for transparency and accountability.

4. TECHNICAL SPECIFICATIONS
---------------------------
- Framework: Laravel (PHP)
- Frontend: Blade Templates with Tailwind CSS
- Database: MySQL
- Build Tool: Vite
- Deployment Environment: Local XAMPP (Development) with remote access capabilities.

5. KEY WORKFLOWS
----------------
1. Allocation: Superadmin sets the department budget.
2. Upload: Ka. Dept uploads detailed budget line items via Excel.
3. Submission: Staff creates a PPBJ -> Ph -> IA.
4. Approval: Request moves through Ka. Dept -> Ka. Div -> Directors.
5. Completion: Once approved, the budget is marked as 'Used' and deducted from the remaining balance.
